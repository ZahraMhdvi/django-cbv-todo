## Features

- User registration
- Login and logout
- Custom user model
- Email-based authentication
- Create tasks
- View tasks
- Edit tasks
- Delete tasks
- Mark tasks as done
- User-specific task lists
- Protected pages for authenticated users
- Responsive user interface
- PostgreSQL database
- Dockerized development environment

## Class-Based Views

The main features are implemented using Django Class-Based Views.

| Feature           | Django View  |
| ----------------- | ------------ |
| Task List         | `ListView`   |
| Create Task       | `CreateView` |
| Edit Task         | `UpdateView` |
| Delete Task       | `DeleteView` |
| Mark Task as Done | `View`       |
| Registration      | `FormView`   |
| Login             | `LoginView`  |
| Logout            | `LogoutView` |
